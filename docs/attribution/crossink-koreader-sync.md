# CrossInk KOReader Sync progress cards

Razor-Crest's KOReader Sync comparison-card presentation adapts the layout and drawing approach developed by **Julia Nguyen** for [CrossInk](https://github.com/uxjulia/CrossInk).

- Original code: `src/activities/reader/KOReaderSyncActivity.cpp` in CrossInk
- Source contribution: [CrossInk commit `1b1156027`](https://github.com/uxjulia/CrossInk/commit/1b1156027)
- Razor-Crest adaptation: `src/activities/reader/KOReaderSyncActivity.cpp`
- Scope: presentation of remote/local progress as bordered cards, percentage bars, chapter and page labels, and an Ahead badge. Razor-Crest retains its own KOReader Sync protocol, decision logic, and input controls.
